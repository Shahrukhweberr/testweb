# AquaWorld Aquarium PHP Website

Multi-page PHP aquarium website with connected navigation.

Pages:
- index.php
- animals.php
- exhibits.php
- visit.php
- tickets.php
- conservation.php

Shared header/footer live in `includes/`, and styling is in `assets/style.css`.

Run locally with:
php -S localhost:8000
Then open http://localhost:8000/
